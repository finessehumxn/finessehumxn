THE FILES THAT GO IN THE REPO ROOT
================================================================

  itinerary.html    the "Cities I Work In" landing page
  lima.html         the Lima trip page
  itinerary.css     shared stylesheet for every future city
  build_trip.py     the generator, not served to the web

Commit all four to the root of finessehumxn/finessehumxn,
alongside index.html. Netlify and GitHub Pages pick them up on
the next deploy. No build step.

Adding a city later means copying the LIMA block inside
build_trip.py, changing the data, and running it. No HTML or
CSS editing.
